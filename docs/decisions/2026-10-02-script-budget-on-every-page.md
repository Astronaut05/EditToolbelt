# 2026-10-02 · The script budgets on every page, in the end-to-end tests

**Decision:**
- `apps/web/e2e/script-budget.spec.ts` loads every page that holds a tool, works or is coming soon, every hub, the home page and every conversion pair page (107 pages), waits for the network to go quiet, and sums the script it received. A page whose tool works is held to 180,000 bytes, every other page to 160,000: the budgets of "Script budget for working tool pages" (docs/DECISIONS.md), now in one place (`apps/web/scripts/script-budget.ts`) that `scripts/lighthouse.ts` reads too.
- It counts what Lighthouse's `resource-summary` counts: each script's bytes on the wire (compressed as `scripts/serve.ts` sends it, headers included), from Chromium's network events, on a desktop and only on the local build, like the axe sweep. It runs in `pnpm e2e`, in about a minute and a half on two workers here, on the build `pnpm e2e` makes (with the workshop). That build's tool pages read 0.3 to 2 KB more than `pnpm build`'s, which Lighthouse loads, so in CI this is the stricter of the two; on `pnpm build`'s output it passes too.
- Next's router prefetches are blocked: every `_rsc=` request, so neither the payloads of the pages a page links to nor the code they pull in arrive. Lighthouse's runs block the same requests (`blockedUrlPatterns: ['*_rsc=*']` in `scripts/lighthouse.ts`, from the Lighthouse prefetch fix). Unblocked, the home page's code (HomeSearch, 4,250 bytes, prefetched from the header's wordmark) lands inside a run or not depending on timing. With them out, Lighthouse read the same bytes as this test on the same build (with the workshop): /remove-background 175,940, /video-converter 175,581, /batch-rename 178,221, /images-to-pdf 174,611, /photo 147,360.
- Lighthouse still checks its six pages for everything else (scores, LCP, CLS, TBT and their script transfer).

**Why:** CI's Lighthouse checks the tool-page budget on two of 68 working tool pages, and 36 of the other 66 had drifted over it unseen (`docs/decisions/2026-10-02-tool-pages-under-script-budget.md`). Lighthouse on every page would take many times as long.
**Reverse:** delete `apps/web/e2e/script-budget.spec.ts` (and move the two budgets back into `scripts/lighthouse.ts`).
